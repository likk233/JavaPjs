二、核心知识点

8.1 引入 MyBatis-Plus

本项目在 pom.xml 中引入的是聚合包 mybatis-plus（包含 core 与 extension），版本 3.5.5。它内嵌了 MyBatis，与既有 MyBatis 代码可共存——同一个工程里 com.chapter01~07 走原生 MyBatis，com.chaperMybatisPlus 走 MP，互不干扰。

xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus</artifactId>
    <version>3.5.5</version>
</dependency>

8.2 建表：sql/mp_student.sql

表 mp_student 的字段设计覆盖了 MP 的高频场景：自增主键、普通字段、乐观锁版本号、逻辑删除标记、两个自动填充的审计字段。

sql
CREATE TABLE mp_student (
    id          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    name        VARCHAR(50)  NOT NULL                 COMMENT '姓名',
    age         INT          DEFAULT NULL             COMMENT '年龄',
    email       VARCHAR(100) DEFAULT NULL             COMMENT '邮箱',
    major       VARCHAR(50)  DEFAULT NULL             COMMENT '专业',
    score       DOUBLE       DEFAULT NULL             COMMENT '分数',
    version     INT          NOT NULL DEFAULT 0       COMMENT '乐观锁版本号',
    deleted     INT          NOT NULL DEFAULT 0       COMMENT '逻辑删除标记 0-未删除 1-已删除',
    create_time DATETIME     DEFAULT NULL             COMMENT '创建时间（自动填充）',
    update_time DATETIME     DEFAULT NULL             COMMENT '更新时间（自动填充）',
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

8.3 实体类五大注解

@TableName 指定表名；@TableId 声明主键及策略；@TableField 控制字段映射与填充；@TableLogic 开启逻辑删除；@Version 开启乐观锁。开启 mapUnderscoreToCamelCase 后，create_time 自动映射到 createTime，无需逐个注解。

java
@TableName("mp_student")
public class Student implements Serializable {

    @TableId(type = IdType.AUTO)          // 数据库自增（最常用）
    private Long id;

    private String name;                  // 驼峰转下划线，自动映射
    private Integer age;
    private String email;
    private String major;

    @TableField(updateStrategy = FieldStrategy.NOT_NULL)   // 为 null 时不参与 UPDATE
    private Double score;

    @Version                              // 乐观锁：更新时 WHERE version=旧值，SET version=旧值+1
    private Integer version;

    @TableLogic                           // 逻辑删除：deleteById 实际执行 UPDATE SET deleted=1
    private Integer deleted;

    @TableField(fill = FieldFill.INSERT)          // INSERT 时自动填充
    private LocalDateTime createTime;

    @TableField(fill = FieldFill.INSERT_UPDATE)   // INSERT 与 UPDATE 时都自动填充
    private LocalDateTime updateTime;
}

8.4 BaseMapper：零 SQL 拿到 17 个方法

接口只要继承 BaseMapper<T>，无需写任何 SQL 和 XML，就自动拥有单表的增删改查能力。

java
public interface StudentMapper extends BaseMapper<Student> {

}

// 使用时像普通 Mapper 一样从 SqlSession 获取代理：
Student student = studentMapper.selectById(1L);
student.setScore(99.0);
int rows = studentMapper.updateById(student);

8.5 关键：MP 必须用 MP 自己的构建链路

不能混用原生 MyBatis 的构建器。原生链路（XMLConfigBuilder → Configuration → SqlSessionFactoryBuilder）不会为 BaseMapper 注入 CRUD 方法，运行时会报 Invalid bound statement。正确链路是：MybatisXMLConfigBuilder 解析出 MybatisConfiguration，注册插件与 GlobalConfig 后，交给 MybatisSqlSessionFactoryBuilder 构建工厂。

java
InputStream is = Resources.getResourceAsStream("mybatisplus/mybatis-plus-config.xml");

// ① 用 MP 的解析器解析 XML → 得到 MP 的 Configuration
MybatisXMLConfigBuilder parser = new MybatisXMLConfigBuilder(is);
MybatisConfiguration configuration = (MybatisConfiguration) parser.parse();

// ② 注册 InnerInterceptor（分页 + 乐观锁）
configuration.addInterceptor(MybatisPlusConfig.buildInterceptor());

// ③ 注册 GlobalConfig（自动填充处理器挂在全局配置上）
GlobalConfig globalConfig = new GlobalConfig();
globalConfig.setMetaObjectHandler(new MyMetaObjectHandler());
GlobalConfigUtils.setGlobalConfig(configuration, globalConfig);

// ④ 用 MP 的工厂构建器
SqlSessionFactory sqlSessionFactory = new MybatisSqlSessionFactoryBuilder().build(configuration);

sqlSession = sqlSessionFactory.openSession(true);   // 自动提交，测试方便
studentMapper = sqlSession.getMapper(StudentMapper.class);

8.6 快速开始：BaseMapper 四大天王

insert 自动回填自增主键与填充字段；deleteById 在 @TableLogic 下变成 UPDATE；批量操作用 selectBatchIds / deleteBatchIds。

java
// 1-1 插入：自动回填 id，并自动填充 createTime/updateTime
Student student = new Student("小明", 20, "xiaoming@test.com", "计算机", 85.0);
int rows = studentMapper.insert(student);
System.out.println("插入后 id=" + student.getId());   // MP 已回填

// 1-2 按 ID 查询
Student s = studentMapper.selectById(1L);

// 1-3 按 ID 更新：updateTime 自动刷新
s.setScore(99.0);
studentMapper.updateById(s);

// 1-4 按 ID 删除（逻辑删除）：实际执行 UPDATE SET deleted=1
studentMapper.deleteById(tmpId);
Student gone = studentMapper.selectById(tmpId);      // 查不到，自动过滤 deleted=1

// 2 批量查询
List<Student> list = studentMapper.selectBatchIds(Arrays.asList(1L, 2L, 3L));

三、对照表 / 参数说明

BaseMapper 常用方法一览

分类方法说明
插入insert(T)插入一条记录，回填主键
删除deleteById(id)按 ID 删除（有 @TableLogic 时为 UPDATE）
删除deleteBatchIds(coll)按 ID 批量删除
删除deleteByMap(map)按 Map 条件删除
更新updateById(T)按 ID 更新（非 null 字段）
更新update(T, Wrapper)按条件构造器更新
查询selectById(id)按 ID 查询
查询selectBatchIds(coll)按 ID 批量查询
查询selectOne(w)查一条（多条会抛异常）
查询selectCount(w)查总数
查询selectList(w)按条件查列表
查询selectMaps(w)返回 Map 列表（适合聚合）
查询selectPage(page, w)分页查询
查询selectByMap(map)按 Map 等值条件查询

IdType 主键策略

策略含义
AUTO数据库自增（本项目使用）
ASSIGN_ID雪花算法生成分布式 ID
ASSIGN_UUID生成 UUID 字符串
INPUT手动赋值

package com.chaperMybatisPlus.entity;

import com.baomidou.mybatisplus.annotation.*;

import java.io.Serializable;
import java.time.LocalDateTime;

@TableName("mp_student")
public class Student implements Serializable {

    private static final long serialVersionUID = 1L;

    @TableId(type = IdType.AUTO)
    private Long id;

    private String name;
    private Integer age;
    private String email;
    private String major;

    @TableField(updateStrategy = FieldStrategy.NOT_NULL)
    private Double score;

    @Version
    private Integer version;

    @TableLogic
    private Integer deleted;

    @TableField(fill = FieldFill.INSERT)
    private LocalDateTime createTime;

    @TableField(fill = FieldFill.INSERT_UPDATE)
    private LocalDateTime updateTime;

    public Student() {
    }

    public Student(String name, Integer age, String email, String major, Double score) {
        this.name = name;
        this.age = age;
        this.email = email;
        this.major = major;
        this.score = score;
    }

    // …… getter / setter / toString 省略（项目内为完整版）
}

    <properties resource="common/db.properties"/>

    <settings>
        <setting name="logImpl" value="LOG4J"/>
        <setting name="mapUnderscoreToCamelCase" value="true"/>

六、注意事项与常见坑

⚠️ 包名拼写：com.chaperMybatisPlus
  • 项目包名是 chaper（少了一个 t），不是 chapter，引用 import 时照抄项目拼写即可。
  • 同理资源目录是 resources/mybatisplus/（没有连字符）。
⚠️ MP 扩展配置不走 XML
  • MybatisXMLConfigBuilder 只解析原生 MyBatis 标签，<globalConfig> 等 MP 扩展标签会被忽略。
  • 本项目统一在 Java 侧注册：addInterceptor() 挂插件，GlobalConfigUtils.setGlobalConfig() 挂填充处理器。
📌 openSession(true) 与主键回填
  • 测试链路统一 openSession(true) 自动提交，增删改立即生效。
  • IdType.AUTO 要求建表时主键确实是 AUTO_INCREMENT，insert 后 MP 自动把新 id 写回实体。

构建链路四步注册（必须烂熟）

初始化的顺序决定了插件和填充是否生效，顺序错误不会报错、只会「静默失效」。

java
// ① 解析 XML → MP 的 Configuration
MybatisXMLConfigBuilder parser = new MybatisXMLConfigBuilder(is);
MybatisConfiguration configuration = (MybatisConfiguration) parser.parse();
// ② 注册插件（分页 + 乐观锁）
configuration.addInterceptor(MybatisPlusConfig.buildInterceptor());
// ③ 注册 GlobalConfig（自动填充）
GlobalConfig globalConfig = new GlobalConfig();
globalConfig.setMetaObjectHandler(new MyMetaObjectHandler());
GlobalConfigUtils.setGlobalConfig(configuration, globalConfig);
// ④ 构建工厂
SqlSessionFactory sqlSessionFactory =
        new MybatisSqlSessionFactoryBuilder().build(configuration);

package com.chaperMybatisPlus;

import com.baomidou.mybatisplus.core.MybatisConfiguration;
import com.baomidou.mybatisplus.core.MybatisSqlSessionFactoryBuilder;
import com.baomidou.mybatisplus.core.MybatisXMLConfigBuilder;
// ... 其余 import 略

public class StudentTest {

    private SqlSession sqlSession;
    private StudentMapper studentMapper;

    @Before
    public void init() throws Exception {
        InputStream is = Resources.getResourceAsStream("mybatisplus/mybatis-plus-config.xml");

        MybatisXMLConfigBuilder parser = new MybatisXMLConfigBuilder(is);
        MybatisConfiguration configuration = (MybatisConfiguration) parser.parse();

        configuration.addInterceptor(MybatisPlusConfig.buildInterceptor());

        GlobalConfig globalConfig = new GlobalConfig();
        globalConfig.setMetaObjectHandler(new MyMetaObjectHandler());
        GlobalConfigUtils.setGlobalConfig(configuration, globalConfig);

        SqlSessionFactory sqlSessionFactory =
                new MybatisSqlSessionFactoryBuilder().build(configuration);

        sqlSession = sqlSessionFactory.openSession(true);
        studentMapper = sqlSession.getMapper(StudentMapper.class);
    }

    @After
    public void destroy() {
        if (sqlSession != null) {
            sqlSession.close();
        }
    }

    // testLambdaQueryWrapper / testUpdateWrapper / testUpdateByIdFieldStrategy /

    // testSelectOnlySomeFields / testGroupBy / testSelectByMap

六、注意事项与常见坑

⚠️ 静默失效三件套
  • 构建器用错 → BaseMapper 方法全报 Invalid bound statement（会报错，好排查）。
  • 插件注册在 build 之后 → 分页/乐观锁静默失效（不报错，难排查）。
  • MetaObjectHandler 没挂 GlobalConfig → 填充静默失效（不报错，难排查）。
  • 口诀：先解析、再插件、后 GlobalConfig、最后 build。
✅ 交付自查清单
  • 12 个知识点各有对应测试方法且全部通过
  • 每条 SQL 都能在 LOG4J 日志中看到 Preparing / Parameters
  • deleteById 的 UPDATE 改写、乐观锁的 WHERE version 都亲眼确认过
  • 能口头复述 MP 构建链路与原生 MyBatis 的三个区别

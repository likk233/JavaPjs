二、核心知识点

8.2.1 QueryWrapper：链式拼 WHERE

条件方法对应 SQL 谓词：eq/gt/lt/ge/le/like/likeRight 等，链式调用默认 AND 连接；末尾可挂 orderByDesc/orderByAsc 排序。

java
QueryWrapper<Student> wrapper = new QueryWrapper<>();
wrapper
        .eq("major", "Computer")        // major = ?
        .gt("score", 70)                // AND score > ?
        .lt("score", 95)                // AND score < ?
        .like("name", "Zhang")          // AND name LIKE '%Zhang%'
        .orderByDesc("score");          // ORDER BY score DESC

List<Student> list = studentMapper.selectList(wrapper);

8.2.2 OR 嵌套

and(w -> ...) 里的条件被括号包裹，配合 .or() 表达 A AND (B OR C) 这种复合逻辑——SQL 谁都不怕，就怕括号丢。

java
wrapper
        .eq("major", "Computer")
        .and(w -> w.gt("score", 90).or().gt("age", 21))
        .orderByDesc("score");
// 等价于：WHERE major='Computer' AND (score>90 OR age>21) ORDER BY score DESC

8.2.3 LambdaQueryWrapper：推荐，类型安全

列名用 Student::getMajor 方法引用代替字符串，重命名字段时编译器直接报错。likeRight 表示「以...开头」（LIKE 'Li%'）。

java
LambdaQueryWrapper<Student> wrapper = new LambdaQueryWrapper<>();
wrapper
        .eq(Student::getMajor, "Software")
        .ge(Student::getScore, 80)
        .likeRight(Student::getName, "Li")
        .orderByAsc(Student::getAge);

List<Student> list = studentMapper.selectList(wrapper);

8.2.4 selectCount 与 selectOne

selectCount 返回总数（LONG）；selectOne 期望恰好一行，匹配到多行会抛 TooManyResultsException。

java
Long count = studentMapper.selectCount(new QueryWrapper<Student>().eq("major", "Computer"));

Student one = studentMapper.selectOne(
        new QueryWrapper<Student>().eq("name", "Zhang San"));

8.2.5 只查部分字段与 selectMaps

Lambda 的 select(...) 指定查询列，未查的属性保持 null；selectMaps 返回 Map 列表，配合聚合列名不用建实体。

java
// 只查 id/name/score
LambdaQueryWrapper<Student> wrapper = new LambdaQueryWrapper<>();
wrapper.select(Student::getId, Student::getName, Student::getScore)
       .gt(Student::getScore, 90);
List<Student> list = studentMapper.selectList(wrapper);   // major 为 null

// selectMaps：返回 Map 列表
QueryWrapper<Student> qw = new QueryWrapper<>();
qw.select("name", "score", "major").eq("major", "Computer");
List<Map<String, Object>> maps = studentMapper.selectMaps(qw);

8.2.6 分组聚合

聚合表达式直接写进 select()，配 groupBy + 别名，结果用 selectMaps 承接——这是 MP 做「简单统计」的标准姿势。

java
QueryWrapper<Student> wrapper = new QueryWrapper<>();
wrapper.select("major", "AVG(score) AS avg_score", "COUNT(*) AS count")
       .groupBy("major")
       .orderByDesc("avg_score");

List<Map<String, Object>> maps = studentMapper.selectMaps(wrapper);
// [{major=计算机, avg_score=83.5, count=3}, ...]

8.2.7 selectByMap 与条件更新

selectByMap 把 Map 的 key-value 变成等值条件；LambdaUpdateWrapper 与 update(entity, wrapper) 组合实现「按条件批量改」。

java
// selectByMap：major=Computer AND age=20
Map<String, Object> map = new HashMap<>();
map.put("major", "Computer");
map.put("age", 20);
List<Student> list = studentMapper.selectByMap(map);

// 条件更新：把 AI 专业且 score<90 的分数改成 100
Student setEntity = new Student();
setEntity.setScore(100.0);                       // 只作为 SET 部分
LambdaUpdateWrapper<Student> wrapper = new LambdaUpdateWrapper<>();
wrapper.eq(Student::getMajor, "AI").lt(Student::getScore, 90);
int rows = studentMapper.update(setEntity, wrapper);

8.2.8 字段策略：NOT_NULL 保护

updateById 默认跳过 null 字段；但把字段「显式置空」的需求会被该默认行为拦住。@TableField(updateStrategy = FieldStrategy.NOT_NULL) 明确声明：为 null 时不参与 UPDATE，防止把原值覆盖成 null。

java
Student student = studentMapper.selectById(2L);
student.setName("李四（改名版）");
student.setScore(null);              // 显式置 null
studentMapper.updateById(student);
// 结果：name 正常更新；score 保持原值（NOT_NULL 策略将其排除在 SET 之外）

六、注意事项与常见坑

📌 字符串列名 vs 方法引用
  • QueryWrapper 的字符串必须写数据库列名（如 major），写错只有运行时才暴露。
  • LambdaQueryWrapper 的方法引用在重命名属性/列时由编译器兜底，团队项目统一推荐 Lambda 版。
⚠️ selectOne 的多行陷阱
  • 条件不唯一时 selectOne 抛 TooManyResultsException。
  • 拿不准就用 selectList 后取第一条，或补足唯一条件。
✅ 聚合场景选 selectMaps
  • AVG/COUNT 这类聚合列没有对应实体属性，用 selectMaps 返回 Map 最省事。
  • 聚合结果要进业务模型时，再定义专门的 VO 并配合 XML 查询。

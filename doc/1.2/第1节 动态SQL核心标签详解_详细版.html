第1节 动态SQL核心标签详解

📚 本节概述
本节深入讲解MyBatis动态SQL的核心标签，包括if、where、set、trim、choose/when/otherwise等标签的原理和使用场景，以及如何在XML映射器中编写灵活的动态SQL语句。掌握动态SQL是MyBatis高级开发的核心技能，学时安排：理论2学时。

一、为什么需要动态SQL

在实际开发中，SQL语句的条件往往是动态变化的。例如用户搜索功能，用户可能只输入了姓名，或只选择了性别，或两者都有，或者什么都没有输入。如果为每种情况都写一个固定SQL，代码会变得非常臃肿。

💡 动态SQL的优势
  • 减少重复代码：一个SQL语句适配多种查询条件
  • 提高代码可维护性：集中管理SQL逻辑
  • 提升性能：减少数据库预编译次数
  • 防止SQL注入：使用参数绑定而非字符串拼接

二、if标签

if标签 — 条件判断

if标签是最基本的动态SQL标签，用于在SQL中添加条件判断。当test属性中的表达式为true时，标签内的SQL片段会被包含进来。

2.1 基础用法

<!-- Mapper接口 -->
List<User> selectByCondition(User user);

/<!-- User.java -->
public class User {
    private String username;
    private String email;
    private Integer status;
    // getters and setters...
}

/*>
<select id="selectByCondition" resultType="com.example.entity.User">
    SELECT id, username, email, status, create_time
    FROM user
    WHERE 1=1
    <if test="username != null and username != ''">
        AND username LIKE CONCAT('%', #{username}, '%')
    </if>
    <if test="email != null and email != ''">
        AND email = #{email}
    </if>
    <if test="status != null">
        AND status = #{status}
    </if>
</select>
⚠️ 注意
使用WHERE 1=1是一个常见的技巧，用于简化动态SQL的编写。如果没有它，每个if标签都需要处理AND/OR的拼接问题。

2.2 多条件组合查询

<select id="complexSearch" resultType="com.example.entity.User">
    SELECT id, username, email, phone, status, create_time
    FROM user
    WHERE 1=1
    <if test="username != null and username.trim() != ''">
        AND username LIKE CONCAT('%', #{username}, '%')
    </if>
    <if test="phone != null and phone != ''">
        AND phone LIKE CONCAT('%', #{phone}, '%')
    </if>
    <if test="status != null">
        AND status = #{status}
    </if>
    <if test="startDate != null and endDate != null">
        AND create_time BETWEEN #{startDate} AND #{endDate}
    </if>
    ORDER BY create_time DESC
</select>

2.3 update语句中的if

<update id="updateByIdSelective" parameterType="com.example.entity.User">
    UPDATE user
    SET
        <if test="username != null and username != ''">
            username = #{username},
        </if>
        <if test="email != null and email != ''">
            email = #{email},
        </if>
        <if test="status != null">
            status = #{status},
        </if>
        update_time = NOW()
    WHERE id = #{id}
</update>

三、where标签

where标签 — 智能条件拼接

where标签可以自动处理WHERE子句中的多余AND/OR关键字。当where标签内的任意if条件满足时，WHERE关键字会被自动添加；如果所有if都不满足，WHERE子句不会被添加。

3.1 替代1=1写法

<select id="selectByCondition" resultType="com.example.entity.User">
    SELECT id, username, email, status, create_time
    FROM user
    <where>
        <if test="username != null and username != ''">
            AND username LIKE CONCAT('%', #{username}, '%')
        </if>
        <if test="email != null and email != ''">
            AND email = #{email}
        </if>
        <if test="status != null">
            AND status = #{status}
        </if>
    </where>
    ORDER BY create_time DESC
</select>
💡 where标签工作原理
  • 自动去掉开头多余的 AND/OR
  • 如果所有if都不满足，整个where块不会生成WHERE关键字
  • 配合if标签使用，无需写 WHERE 1=1

四、set标签

set标签 — UPDATE语句动态列更新

set标签用于UPDATE语句，可以自动处理SET子句中多余的逗号。当标签内有任意一个if满足时，SET关键字会被自动添加。

<update id="updateByIdSelective" parameterType="com.example.entity.User">
    UPDATE user
    <set>
        <if test="username != null and username != ''">
            username = #{username},
        </if>
        <if test="email != null and email != ''">
            email = #{email},
        </if>
        <if test="phone != null and phone != ''">
            phone = #{phone},
        </if>
        <if test="status != null">
            status = #{status},
        </if>
        update_time = NOW()
    </set>
    WHERE id = #{id}
</update>
⚠️ set标签注意事项
set标签会自动去掉末尾的逗号，但如果所有if都不满足，会导致SQL语法错误（没有SET子句）。建议在set标签内至少包含一个恒为true的条件或非空字段。

五、trim标签

trim标签 — 自定义前后缀处理

trim标签是最灵活的标签，可以自定义要添加的前缀和要删除的前缀/后缀。它相当于if+where和if+set的底层实现。

5.1 trim替代where

<!-- 等价于 <where> -->
<select id="selectByCondition" resultType="com.example.entity.User">
    SELECT id, username, email, status
    FROM user
    <trim prefix="WHERE" prefixOverrides="AND|OR">
        <if test="username != null">AND username = #{username}</if>
        <if test="status != null">AND status = #{status}</if>
    </trim>
</select>

5.2 trim替代set

<!-- 等价于 <set> -->
<update id="updateByIdSelective">
    UPDATE user
    <trim suffixOverrides="," suffix="WHERE id = #{id}">
        <if test="username != null">username = #{username},</if>
        <if test="email != null">email = #{email},</if>
        <if test="status != null">status = #{status},</if>
        update_time = NOW(),
    </trim>
</update>

六、choose/when/otherwise标签

choose标签 — 多选一逻辑

choose/when/otherwise类似于Java中的if-else if-else结构。当多个条件中只选择一个时使用。一旦某个when条件满足，后面的when不再判断。

<select id="searchByPriority" resultType="com.example.entity.User">
    SELECT id, username, email, status
    FROM user
    <where>
        <choose>
            <when test="id != null">
                AND id = #{id}
            </when>
            <when test="username != null and username != ''">
                AND username = #{username}
            </when>
            <when test="email != null and email != ''">
                AND email = #{email}
            </when>
            <otherwise>
                AND status = 1
            </otherwise>
        </choose>
    </where>
</select>
💡 场景说明
choose标签适合"优先级搜索"场景：如按ID精确查询 > 按用户名精确查询 > 按邮箱精确查询 > 默认查询激活用户。

七、动态SQL标签总结

标签作用使用场景
<if>条件判断任何需要条件过滤的地方
<where>智能WHERE子句SELECT语句的动态条件拼接
<set>智能SET子句UPDATE语句的动态列更新
<trim>自定义前后缀需要细粒度控制前缀/后缀时
<choose>多选一逻辑互斥条件，只满足一个
📝 本节小结
  • <if>标签：最基本的条件判断，通过test属性指定OGNL表达式
  • <where>标签：自动处理WHERE关键字和多余AND/OR，推荐替代WHERE 1=1写法
  • <set>标签：用于UPDATE语句，自动处理SET子句中多余的逗号
  • <trim>标签：最通用的标签，可以完全替代where和set
  • <choose>标签：实现if-else if-else的多选一逻辑

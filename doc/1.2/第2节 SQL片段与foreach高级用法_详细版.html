第2节 SQL片段与foreach高级用法

📚 本节概述
本节讲解MyBatis中sql标签定义可复用片段，以及foreach标签的批量操作能力。包括批量插入、批量更新、IN查询等常见场景的解决方案。学时安排：理论2学时。

一、sql标签 — SQL片段复用

1.1 为什么需要SQL片段

在实际的Mapper.xml文件中，很多SELECT语句会有重复的列名列表。通过<sql>标签可以定义可复用的SQL片段，减少重复代码，提高可维护性。

1.2 定义和引用SQL片段

<!-- 定义SQL片段 -->
<sql id="userColumns">
    id, username, email, phone, status, create_time, update_time
</sql>

<!-- 在SELECT中引用 -->
<select id="selectAll" resultType="com.example.entity.User">
    SELECT <include refid="userColumns"/>
    FROM user
</select>

<!-- 在另一个SELECT中复用 -->
<select id="selectById" resultType="com.example.entity.User">
    SELECT <include refid="userColumns"/>
    FROM user
    WHERE id = #{id}
</select>

1.3 SQL片段中引用其他片段

<sql id="commonColumns">
    id, create_time, update_time
</sql>

<sql id="userColumns">
    <include refid="commonColumns"/>,
    username, email, phone, status
</sql>
💡 SQL片段最佳实践
  • 将通用的列名定义为SQL片段，便于统一管理和修改
  • 片段中可以包含WHERE条件、JOIN条件等复杂内容
  • 片段中可以再引用其他片段，形成组合
  • 片段应该在文件顶部定义，方便查找和维护

二、foreach标签 — 批量操作

2.1 foreach标签属性

属性说明示例
collection要遍历的集合/数组/Maplist / array / ids
item遍历时每个元素的变量名item / user / id
index遍历时的索引（从0开始）index
open循环开始前添加的字符(
close循环结束后添加的字符)
separator元素之间的分隔符,

2.2 批量IN查询

最常见的场景：根据多个ID查询记录。

<!-- Mapper接口 -->
List<User> selectByIds(@Param("ids") List<Long> ids);

/*>
<select id="selectByIds" resultType="com.example.entity.User">
    SELECT <include refid="userColumns"/>
    FROM user
    WHERE id IN
    <foreach collection="ids" item="id" open="(" separator="," close=")">
        #{id}
    </foreach>
</select>
💡 生成效果
当ids=[1,2,3,5,8]时，最终SQL为：WHERE id IN (1, 2, 3, 5, 8)

2.3 批量插入

<!-- Mapper接口 -->
int batchInsert(@Param("users") List<User> users);

/*>
<insert id="batchInsert" parameterType="java.util.List">
    INSERT INTO user (username, email, phone, status, create_time) VALUES
    <foreach collection="users" item="user" separator=",">
        (
            #{user.username},
            #{user.email},
            #{user.phone},
            #{user.status},
            NOW()
        )
    </foreach>
</insert>
⚠️ 批量插入注意事项
  • MySQL批量插入建议不超过1000条，超过建议分批执行
  • Oracle数据库使用foreach批量插入时语法略有不同
  • MyBatis的foreach会生成一条SQL，效率远高于循环单条插入

2.4 批量更新（MySQL）

<!-- Mapper接口 -->
int batchUpdateStatus(@Param("ids") List<Long> ids, @Param("status") Integer status);

/*>
<update id="batchUpdateStatus">
    UPDATE user SET status = #{status}, update_time = NOW()
    WHERE id IN
    <foreach collection="ids" item="id" open="(" separator="," close=")">
        #{id}
    </foreach>
</update>

2.5 批量更新（多值更新）

<!-- Mapper接口 -->
int batchUpdateUsers(@Param("users") List<User> users);

/*>
<update id="batchUpdateUsers">
    <foreach collection="users" item="user" separator=";">
        UPDATE user
        SET
            username = #{user.username},
            email = #{user.email},
            status = #{user.status},
            update_time = NOW()
        WHERE id = #{user.id}
    </foreach>
</update>

2.6 使用foreach构建动态IN子句

<!-- 多字段IN查询 -->
<select id="selectByMultiConditions" resultType="com.example.entity.Order">
    SELECT id, order_no, user_id, amount, status
    FROM orders
    WHERE (user_id, status) IN
    <foreach collection="conditions" item="cond" open="(" separator="," close=")">
        (#{cond.userId}, #{cond.status})
    </foreach>
</select>

三、动态SQL综合应用

3.1 动态多条件查询（带分页）

<select id="dynamicSearch" resultType="com.example.entity.User">
    SELECT <include refid="userColumns"/>
    FROM user
    <where>
        <if test="username != null and username != ''">
            AND username LIKE CONCAT('%', #{username}, '%')
        </if>
        <if test="email != null and email != ''">
            AND email = #{email}
        </if>
        <if test="status != null">
            AND status = #{status}
        </if>
        <if test="ids != null and ids.size() > 0">
            AND id IN
            <foreach collection="ids" item="id" open="(" separator="," close=")">
                #{id}
            </foreach>
        </if>
    </where>
    ORDER BY create_time DESC
    LIMIT #{offset}, #{limit}
</select>

3.2 动态SET更新

<update id="dynamicUpdate">
    UPDATE user
    <set>
        <if test="username != null and username != ''">
            username = #{username},
        </if>
        <if test="email != null and email != ''">
            email = #{email},
        </if>
        <if test="phone != null and phone != ''">
            phone = #{phone},
        </if>
        update_time = NOW(),
    </set>
    WHERE id = #{id}
</update>

四、性能优化建议

💡 foreach性能优化
  • 批量IN查询：当IN的值过多（>1000）时，建议分批查询或改用临时表
  • 批量插入：使用MySQL的批量INSERT语法，单次最多插入1000条
  • foreach循环更新：每条SQL前需要设置allowMultiQueries=true
  • 避免在foreach中做复杂计算：foreach中的表达式应尽量简单
  • 使用@Param注解：明确指定参数名，避免collection取值错误
操作类型推荐批量大小说明
批量INSERT500-1000条/次MySQL单条SQL最大长度限制
批量IN查询<1000个值超过建议拆分为多个IN
批量UPDATE（多语句）100-500条/次依赖allowMultiQueries
📝 本节小结
  • <sql>标签用于定义可复用的SQL片段，通过<include>引用
  • <foreach>标签是批量操作的核心，支持批量IN查询、批量插入、批量更新
  • 批量INSERT语法效率最高，避免在Java代码中循环调用单条INSERT
  • foreach的collection属性可以指定List、Array或Map的key
  • 批量操作需要注意SQL长度和数据库参数限制

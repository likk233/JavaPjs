步骤3：创建IdCardMapper接口

在 com.example.mapper 包下创建 IdCardMapper.java：

package com.example.mapper;

import com.example.pojo.IdCard;
import org.apache.ibatis.annotations.*;
import java.util.List;

public interface IdCardMapper {
    
    /**
     * 根据ID查询身份证
     */
    @Select("SELECT * FROM id_card WHERE card_id = #{cardId}")
    @Results(id = "idCardResultMap", value = {
        @Result(property = "cardId", column = "card_id", id = true),
        @Result(property = "userId", column = "user_id"),
        @Result(property = "cardNo", column = "card_no"),
        @Result(property = "address", column = "address")
    })
    IdCard findById(Integer cardId);
    
    /**
     * 根据用户ID查询身份证
     */
    @Select("SELECT * FROM id_card WHERE user_id = #{userId}")
    @ResultMap("idCardResultMap")
    IdCard findByUserId(Integer userId);
    
    /**
     * 查询身份证及其对应的用户（一对一关联）
     */
    @Select("SELECT * FROM id_card WHERE card_id = #{cardId}")
    @Results({
        @Result(property = "cardId", column = "card_id", id = true),
        @Result(property = "userId", column = "user_id"),
        @Result(property = "cardNo", column = "card_no"),
        @Result(property = "address", column = "address"),
        @Result(property = "user", column = "user_id",
                one = @One(select = "com.example.mapper.UserMapper.findById"))
    })
    IdCard findIdCardWithUser(Integer cardId);
}
说明：
  • @One 注解用于配置一对一关联
  • select 属性指定关联查询的方法（全限定名）
  • column 属性指定传入关联查询方法的参数（外键字段）
步骤4：在UserMapper中添加关联查询方法

打开 UserMapper.java，添加以下方法：

/**
 * 查询用户及其身份证（一对一关联）
 */
@Select("SELECT * FROM user WHERE id = #{id} AND deleted = 0")
@Results({
    @Result(property = "id", column = "id", id = true),
    @Result(property = "username", column = "username"),
    @Result(property = "password", column = "password"),
    @Result(property = "age", column = "age"),
    @Result(property = "email", column = "email"),
    @Result(property = "idCard", column = "id",
            one = @One(select = "com.example.mapper.IdCardMapper.findByUserId",
                       fetchType = FetchType.LAZY))
})
User findUserWithIdCard(Integer id);
✅ fetchType = FetchType.LAZY 表示延迟加载

即：只有在调用 user.getIdCard() 时才执行查询身份证的SQL。

创建测试类 IdCardMapperTest.java：

package com.example.test;

import com.example.mapper.IdCardMapper;
import com.example.mapper.UserMapper;
import com.example.pojo.IdCard;
import com.example.pojo.User;
import org.junit.Test;

public class IdCardMapperTest extends BaseTest {
    
    /**
     * 测试一对一关联：查询用户及其身份证
     */
    @Test
    public void testFindUserWithIdCard() {
        UserMapper mapper = sqlSession.getMapper(UserMapper.class);
        
        // 查询用户（带有身份证信息）
        User user = mapper.findUserWithIdCard(1);
        
        System.out.println("用户：" + user.getUsername());
        System.out.println("年龄：" + user.getAge());
        
        // 访问关联属性（此时才会执行查询身份证的SQL）
        if (user.getIdCard() != null) {
            System.out.println("身份证号：" + user.getIdCard().getCardNo());
            System.out.println("地址：" + user.getIdCard().getAddress());
        }
        
        assert user != null : "用户不应该为null";
    }
    
    /**
     * 测试一对一关联：查询身份证及其用户
     */
    @Test
    public void testFindIdCardWithUser() {
        IdCardMapper mapper = sqlSession.getMapper(IdCardMapper.class);
        
        // 查询身份证（带有用户信息）
        IdCard idCard = mapper.findIdCardWithUser(1);
        
        System.out.println("身份证号：" + idCard.getCardNo());
        System.out.println("地址：" + idCard.getAddress());
        
        // 访问关联属性
        if (idCard.getUser() != null) {
            System.out.println("所属用户：" + idCard.getUser().getUsername());
        }
        
        assert idCard != null : "身份证不应该为null";
    }
}

实验3：延迟加载配置与使用

步骤1：开启延迟加载（全局配置）

打开 mybatis-config.xml，添加以下配置：

<settings>
    <!-- 开启驼峰命名自动映射 -->
    <setting name="mapUnderscoreToCamelCase" value="true"/>
    
    <!-- 开启延迟加载 -->
    <setting name="lazyLoadingEnabled" value="true"/>
    
    <!-- 关闭积极加载 -->
    <setting name="aggressiveLazyLoading" value="false"/>
    
    <!-- 打印SQL日志 -->
    <setting name="logImpl" value="STDOUT_LOGGING"/>
</settings>
配置说明：
  • lazyLoadingEnabled：是否开启延迟加载（true/false）
  • aggressiveLazyLoading：是否积极加载（false表示按需加载）
步骤2：在注解中单独配置延迟加载

可以在 @One 或 @Many 注解中单独配置 fetchType：

// 延迟加载（LAZY）
@Result(property = "orders", column = "id",
        many = @Many(select = "...",
                     fetchType = FetchType.LAZY))

// 立即加载（EAGER）
@Result(property = "orders", column = "id",
        many = @Many(select = "...",
                     fetchType = FetchType.EAGER))
✅ 说明：

注解中的 fetchType 会覆盖全局配置。

修改测试方法，观察SQL执行时机：

    System.out.println("=== 访问订单属性 ===");

    System.out.println("=== 输出订单信息 ===");

}

package com.example.mapper;

import com.example.pojo.Student;
import org.apache.ibatis.annotations.*;
import java.util.List;

public interface StudentMapper {

     * 查询学生及其所选课程（多对多关联）

        @Result(property = "studentId", column = "student_id", id = true),
        @Result(property = "studentName", column = "student_name"),
        @Result(property = "age", column = "age"),

        @Result(property = "studentName", column = "student_name"),
        @Result(property = "age", column = "age")

package com.example.mapper;

import com.example.pojo.Course;

import java.util.List;

public interface CourseMapper {

        @Result(property = "courseId", column = "course_id", id = true),
        @Result(property = "courseName", column = "course_name"),

常见问题

问题1：关联查询时出现无限递归

原因：双向关联（User中有IdCard，IdCard中有User）且都设置为立即加载。

解决方案：将其中一方设置为延迟加载（LAZY）。

问题2：延迟加载不生效

原因：未开启延迟加载配置，或者SqlSession已关闭。

解决方案：检查 mybatis-config.xml 配置，确保在SqlSession关闭前访问关联属性。

问题3：N+1问题导致性能低下

原因：查询多个用户时，每个用户都会执行一次订单查询（共N+1次查询）。

解决方案：对于必须立即加载的关联数据，使用JOIN查询；对于不常用的关联数据，使用延迟加载。
